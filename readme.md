# Learning Cybersecurity

This repo is intended to document my progress while I learn cybersecurity through TryHackMe's course.

After I complete a course lesson, the LLM will generate questions based on the material. I will then answer the questions to the best of my knowledge to which the LLM will give me feedback or corrections. Even if my answers are incorrect or don't show a clear understanding of the material, they will remain visible to highlight my progress and the LLM will ask follow-up questions to ensure I'm digesting the material.

If I am not certain on a topic, the questions will continue until I can explain it confidently in my own words. All the entries that are marked (OLD) cover lessons I completed earlier but used a different method of documentation. This new method of documentation focuses more on fully understanding the concepts and demonstrating my progress.
