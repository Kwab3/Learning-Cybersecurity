## Active Recall

### 1. How do laptops, desktops, workstations, and servers differ?

> A laptop is a portable computer that sacrifices efficiency for mobility. A desktop is the opposite: a fixed computer that sacrifices mobility for efficiency.
>
> A workstation is found in professional environments and can have specialized components to reduce errors during long or complex computations. A server operates over a network and provides services to multiple users.

**Result:** Mostly correct—“sustained performance” is more precise than “efficiency.”

### 2. Which computer should perform long, accuracy-sensitive 3D simulations?

> The company should use a workstation with specialized components. The workstation will be reliable and reduce errors, which should help with calculation accuracy.

**Result:** Correct.

### 3. What is the difference between an IoT device and an embedded computer?

> An IoT device operates over a network to send data or receive commands, while embedded computers usually have a predetermined task. A fitness tracker is an IoT device, while a coffee-machine controller is an embedded computer.

**Result:** Mostly correct—embedded systems can also have network connectivity.

### 4. Why isn’t there one best type of computer?

> Each type of computer comes with advantages and trade-offs. Smartphones trade processing power for mobility and network access. Desktops trade mobility for better processing power at a fixed location because fans can cool the computer properly.

**Result:** Correct overall—portable devices specifically prioritize mobility, connectivity, and battery life over sustained performance.

### 5. How does redundancy improve server reliability?

> Redundancy provides a backup layer to fall on if the server fails. This does not guarantee that the server will never fail, but it greatly reduces the odds of failure.

**Result:** Mostly correct—redundant components take over when individual hardware components fail.

### 6. How would you classify an automatic-door controller and a smart thermostat?

> I would classify the automatic door as an embedded computer because its sole purpose is to open or close the door. I would classify the smart thermostat as an IoT device because, even though it has an embedded computer tracking the temperature, it connects to Wi-Fi to send data elsewhere.

**Result:** Correct—the thermostat is both an embedded computer and an IoT device.

## Corrections Retained

- Portable computers primarily trade sustained performance, cooling capacity, and power availability for mobility.
- “Embedded” and “IoT” are overlapping classifications; a device can be both.
- Server redundancy uses extra components, such as power supplies and disks, to tolerate individual hardware failures.
